# LibreLogin-Paper

Standalone Paper implementation of LibreLogin.

This component is part of a fork/customized distribution based on [LibreLogin](https://github.com/kyngs/LibreLogin).

The upstream license and attribution are retained in the release package.

## When to use it

Use this artifact when LibreLogin is handling authentication directly on a Paper server. It includes the Paper authentication flow, database integration, login listeners and optional 2FA support for that standalone deployment.

For a Velocity network where `LibreLogin-Velocity` handles authentication, do **not** install this jar on the proxied `auth` backend. Use `AuthLimbo` on that backend instead.

## Install

Copy `LibreLogin-Paper-0.24.5.jar` into the Paper `plugins/` directory and start the server. The plugin generates `config.yml` and `messages.yml` in its data folder.

Use Paper, Java 21 or newer, and a database supported by the generated configuration. Back up the plugin data folder and database before upgrading from an older release.

## Configuration

The main configuration is `config.yml`. Important sections include:

- `database` — database type and connection properties.
- `limbo` — Paper worlds used for unauthenticated players; missing limbo worlds can be generated by LibreLogin.
- `lobby` — destination worlds after authentication.
- `totp` — TOTP/2FA settings.
- `use-titles` and `use-action-bar` — login notifications.

Messages are in `messages.yml`. The prefix is configurable and literal:

```yaml
prefix: "LibreLogin"
```

Set it to an empty string to disable it:

```yaml
prefix: ""
```

## 2FA

The exact image-projection capability depends on the installed compatible integration and client protocol. Follow the generated configuration and test the selected Paper/client version combination before production use.

## Dependencies

The jar uses Libby to load runtime libraries declared by the build, including database drivers and authentication support libraries. Optional integrations such as LuckPerms and Floodgate are detected when installed.

NanoLimbo is not a dependency of this artifact.
